If Else

"if else" is used to make decisions in the program. if checks a condition and else runs when it's false.

Else if and nested if

else if adds more conditions, always in order: if, then else if, then else. A nested if checks a second condition only when the outer one is true.

or, and, not & includes

or (||)

Needs only one condition to be true.

and (&&)

Needs both conditions to be true.

not (!)

Inverts the condition.

includes

Checks if a value is inside an array.

Inline if else (ternary)

An inline if else uses the ? : ternary operator.

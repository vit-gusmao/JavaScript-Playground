Types of Variables

Variables store values in memory. They work like "boxes" that hold information you can use later in the code.

let and const

let

let can be reassigned at any time.

const

const is declared once. Its value can't be reassigned.

How to declare variables

A variable name can only start with a letter, $, or _. It cannot start with a number and cannot contain special characters.

✅ Valid names

myVar, _private, $jquery, first_name

❌ Invalid names

1stVar, my-var, my var, class

camelCase

First word lowercase, each following word capitalized: firstName, isUserLoggedIn.

Variables

What are variables?

Variables are designed to store values in memory. They work like "boxes" that store information which can be used later in the code.

Two types of variables

let

let is a variable that can be redeclared and reassigned at any time.

Reassignment example:

let number = 3;
number = 4;
alert(number);

// Shows "4" in the alert

const

const is a constant that can be declared only once. Its value cannot be reassigned.

Example:

const PI = 3.14;
// PI = 3.15;  // ❌ Error!

console.log(PI); // 3.14

How to declare variables ?

A variable name can only start with a letter, $, or _
It cannot start with a number and cannot contain special characters.

✅ Valid names

let myVar = 'valid';
let _private = 123;
let $jquery = {};
let first_name = 'John';

❌ Invalid names

let 1stVar = 'invalid';
let my-var = 123;
let my var = 'space';
let class = {};

CamelCase convention

The best way to declare a variable is to use the camelCase convention, where the first word is in lowercase and each following word starts with a capital letter, without spaces or underscores.

✨ Example:

let helloWorld = "Hello World!";
let firstName = "John";
let isUserLoggedIn = true;
let getUserData = () => { ... };

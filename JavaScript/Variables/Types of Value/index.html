Values

What are values ?

Values are the kinds of data that variables can hold, like the "content" inside the box, each variable can store a value of one of these types.
The type of value determines what you can do with that variable in your code.

types of Values

String

A string is a sequence of characters, usually used to represent text values.

Example:

let name = "Maria";

console.log("Welcome, ${name}"); // Welcome, Maria

Number

A number is a numeric value, which can be an integer or a decimal (floating point).

Example:

let age = 25;
let price = 9.99;
let num = 2e10;

console.log(age + price); // 34.99
console.log(num); // 20000000000

Boolean

A boolean represents a logical value and can only be true or false.

anything that has a value is considered true, while anything that is null is considered false.

Example:

let isLoggedIn = true;
let isAdult = false;
let productsLeft = 0;
let productList = 1;

console.log(isLoggedIn); // true
console.log(isAdult); // false
console.log(productsLeft); // false
console.log(productList); // true

Undefined

undefined means a variable has been declared but has not yet been assigned any value.

Example:

let result;

console.log(result); // undefined

Null

null is a special value that represents the intentional absence of any object value. It is often used to indicate that a variable should be empty, or has no value on purpose.

Example:

shoppingCartPrice = null;
console.log(shoppingCartPrice); // null

Typeof

The typeof operator in JavaScript is used to find out the type of a value or variable. It returns a string indicating the type, such as "string", "number", "boolean", "undefined", etc.

Example:

let age = 30;
let name = "Anna";
let isStudent = false;

console.log(typeof age); // "number"
console.log(typeof name); // "string"
console.log(typeof isStudent); // "boolean"

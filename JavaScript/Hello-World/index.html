Hello World

Every language starts here. A minimal JavaScript program just runs a line of code — no setup, no build step, just the browser reading your script.

The two most common ways to see JavaScript output while learning are console.log(), which writes to the browser's DevTools console, and alert(), which pops a message box on top of the page. Open DevTools (F12 or right-click → Inspect) and switch to the Console tab before running the examples below.

console.log()

Prints a value to the DevTools console. The most used debugging tool in JavaScript.

alert()

Shows a blocking dialog box in the browser. Useful to learn, rarely used in real apps.

DevTools

Every browser ships with a console built in — your first debugging tool.

Function

What are functions ?

A function is a reusable block of code designed to perform a particular task.

Example:

function welcome() {
    console.log("Welcome");
}

welcome(); // Welcome

Parameters and returns

Functions can have parameters and returns.

Parameter

A parameter is a value you pass into the function to change what it does.

Example:

function caller(message, name) {
    console.log(message, name);
}

caller("Hello", "André"); // Hello André
caller("Good Morning", "Paulo"); // Good Morning Paulo
caller("Good Night", "Zoe"); // Good Night Zoe

Return

return sends a value back from the function. Code after return does not run.

Example:

function callerNick(nickname) {
    return `Welcome, ${nickname}`;
}

console.log(callerNick("André")); // Welcome, André

Anonymous functions

An anonymous function has no name. It can be stored as a value or passed as an argument to another function.

Example:

const calling = {
    showMessage: function () {
        return "Hello";
    }
};

console.log(calling.showMessage()); // Hello

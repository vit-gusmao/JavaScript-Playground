What is for ?

A for loop repeats a block of code a specific number of times, with a counter, condition and increment.

The syntax is for (counter; condition; increment).

counter

counter usually starts at 0.

Example:

let i = 0;

condition

The loop runs while the condition is true.

Example:

i < 3

increment

increment changes the counter, like i++.

Example:

i++

Example:

const quantity = 3;
const phrases = ["Hello", "JavaScript", "Playground"];

for (let i = 0; i < quantity; i++) {
    console.log(phrases[i]);
}
// Hello
// JavaScript
// Playground

const showCount = 2;

for (let i = 0; i < showCount; i++) {
    console.log(phrases[i]);
}
// Hello
// JavaScript

For Each

for (item of array) walks through every element of an array. item stores the value of each element, and array is the list being read.

item

item is the variable that stores the value of each element of the array.

Example:

for (const num of numbers) {
    console.log(num);
}

array

array is the list that will be walked through, from the first item to the last.

Example:

const numbers = [10, 20, 30];

for (const num of numbers) {
}

Example:

const numbers = [10, 20, 30];

console.log("All numbers:", numbers.join(", "));
// All numbers: 10, 20, 30

console.log(numbers.join(" + "));
// 10 + 20 + 30

let sum = 0;
for (const num of numbers) {
    sum += num;
}

console.log("=", sum);
// = 60

forEach method:

forEach is an array method that also walks through every element.

const values = [10, 20, 30];
let total = 0;

values.forEach(function (num) {
    total += num;
});

console.log(total); // 60

Variables

What is variables ?

Variables are designed to store values in memory.

There are 2 types of variables, "let" and "const"

let

let is a variable wich can be redeclared and assigned any time

Example:

let number = 3;
number = 4;
alert(number)

it will show "4" in the alert

const

const is a variable wich can only be declared once, always being the assigned value, it can't be redeclared

How to declare variables?

A variable name can only start with a letter, $, or _
It cannot start with a number and cannot contain special characters.

camelCase pattern

The best way to declare a variable is using the camelCasenaming convention, where the first word is in lowercase and each following word starts with a capital letter, with no spaces or underscores.<\p>

Example:

let helloWorld = "Hello World!";

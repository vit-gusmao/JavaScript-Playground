Values

What are values ?

Values are the kinds of data that variables can hold, like the "content" inside the box, each variable can store a value of one of these types.
The type of value determines what you can do with that variable in your code.

types of Values

String

A string is a sequence of characters, usually used to represent text values.

Example:

let name = "Maria";
console.log("Welcome, ${name}"); // Welcome, Maria

Number

A number is a numeric value, which can be an integer or a decimal (floating point).

Example:

let age = 25;
let price = 9.99;
console.log(age + price); // 34.99

Boolean

A boolean represents a logical value and can only be true or false.

Example:

let isLoggedIn = true;
let isAdult = false;
console.log(isLoggedIn); // true

Undefined

undefined means a variable has been declared but has not yet been assigned any value.

Example:

let result;
console.log(result); // undefined

How to declare variables ?

A variable name can only start with a letter, $, or _
It cannot start with a number and cannot contain special characters.

✅ Valid names

let myVar = 'valid';
let _private = 123;
let $jquery = {};
let first_name = 'John';

❌ Invalid names

let 1stVar = 'invalid';
let my-var = 123;
let my var = 'space';
let class = {};

CamelCase convention

The best way to declare a variable is to use the camelCase convention, where the first word is in lowercase and each following word starts with a capital letter, without spaces or underscores.

✨ Example:

let helloWorld = "Hello World!";
let firstName = "John";
let isUserLoggedIn = true;
let getUserData = () => { ... };

Function

What are functions ?

A Function is a reusable block of code designed to perform a particular task.

Example:

function welcoming(){
    console.log("welcome");
}

welcoming(); // "welcome"

Paramaters and returns

Functions can have paramaters and returns.

parameter

parameter is a variable value inside of the function where you can pass it for change his value.

example:

function caller(message, name){
    console.log(message, name);
}

caller("Hello", "André"); // Hello André
caller("Good Morning", "Paulo"); // Good Morning Paulo
caller("Good Night", "Zoe"); // Good Night Zoe

Return

A return is used to return something in the function, codes after the return wont be readed.

Example:

function callerNick(nickname){
    return "Welcome, ${nickname}";
}

console.log(callerNick("André")); // Welcome, André

Anonymous Functions

Anonymous Functions are to define a function as a value or pass it as an argument to another function, without the need to declare it separately with a name.

Example:

const calling = {
    showMessage: function() {
        return "Hello";
    }
}

console.log(calling.showMessage()); // Hello

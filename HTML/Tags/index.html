Tags

The building blocks of a page

Tags mark up content so the browser knows how to display it: headings for titles, paragraphs for text, links to navigate, images to display media and lists to group items.

Headings & paragraphs

h1-h6 for titles, p for text.

Links

a with an href attribute navigates to another page or section.

Images & lists

img displays media, ul/ol group items with li.

Example:

<h1>Welcome</h1>
<p>This is a paragraph of text.</p>

<a href="https://developer.mozilla.org">MDN Docs</a>

<img src="./photo.jpg" alt="A description of the photo">

<ul>
    <li>First item</li>
    <li>Second item</li>
</ul>

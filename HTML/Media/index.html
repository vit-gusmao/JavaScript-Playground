Media

The audio and video elements embed media directly, no plugins required.

controls

Shows the browser's built-in play/pause/volume UI.

source

Offers multiple file formats; the browser picks one it supports.

Fallback text

Shown only in browsers that can't play the element at all.

Try it: never add autoplay together with sound — it's disruptive and most browsers block it anyway.

Forms

Collecting input from the user

A form element groups inputs together and sends their data somewhere. Each field should have a label so it stays accessible.

Inputs

input types like text, email and password.

Labels

label connects to an input via the for/id pair.

Validation

Attributes like required and pattern validate before submit.

Example:

<form action="/subscribe" method="post">
    <label for="email">Email</label>
    <input type="email" id="email" name="email" required>

    <label for="age">Age</label>
    <input type="number" id="age" name="age" min="0">

    <button type="submit">Subscribe</button>
</form>

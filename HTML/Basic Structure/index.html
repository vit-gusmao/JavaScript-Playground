What makes up an HTML document ?

Every HTML page starts with a doctype declaration, followed by an html element containing a head (metadata) and a body (visible content).

<!DOCTYPE html>

Tells the browser this is an HTML5 document.

<head>

Holds meta tags, the title and links to CSS/JS, none of it is rendered on screen.

<body>

Contains everything the visitor actually sees: text, images, forms and more.

Example:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Page</title>
</head>
<body>
    <h1>Hello, world!</h1>
</body>
</html>

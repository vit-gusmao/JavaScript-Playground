HTML5 Features

A quick map of the elements and APIs HTML5 added on top of the basics — not a full spec, just what's worth knowing exists.

figure & figcaption

An image (or other media) with its own caption.

time

Marks up a date or time in a machine-readable way.

details & summary

A native collapsible disclosure widget, no JavaScript needed.

Try it: HTML5 also introduced JavaScript APIs like localStorage for saving data in the browser — a topic of its own, beyond markup.

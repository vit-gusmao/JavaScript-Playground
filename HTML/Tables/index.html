Tables

Displaying tabular data

A table is built from rows (tr) containing cells (td for data, th for headers), optionally grouped into thead and tbody.

tr & td

Table row and table data cell.

th

A header cell, bold and centered by default.

thead & tbody

Group the header row apart from the body rows.

Example:

<table>
    <thead>
        <tr>
            <th>Name</th>
            <th>Age</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>João</td>
            <td>15</td>
        </tr>
    </tbody>
</table>

Introduction

HTML (HyperText Markup Language) structures a web page. Every document starts with a doctype, followed by an html element containing a head and a body.

<!DOCTYPE html>

Tells the browser this is an HTML5 document.

<head>

Holds meta tags, the title and links to CSS/JS. Nothing here is rendered.

<body>

Contains everything the visitor actually sees.

Document tree

Try it: every element you write in the body is nested inside another — this parent/child relationship is the "document tree" that CSS and JavaScript navigate later.

Semantic HTML

Tags that describe meaning, not just layout

Semantic elements like header, nav and main tell the browser and screen readers what a section of the page actually is.

header & footer

Top and bottom regions of a page or article.

nav & main

nav holds navigation links, main holds the page's primary content.

section & article

section groups related content, article is self-contained content.

Example:

<header>
    <nav>...</nav>
</header>

<main>
    <article>
        <h2>Blog post title</h2>
        <p>Post content...</p>
    </article>
</main>

<footer>
    <p>&copy; 2026</p>
</footer>

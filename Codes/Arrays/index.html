Arrays

What are arrays ?

A array is a list full of values, the position(index) of the values starting from 0.
Unique lists are called vector and lists of others lists are called matrix.

Vector:

const names = ["André", "José", "Gustavo"];

console.log(names[0], names[1], names[2]); // André José Gustavo

Matrix:

const bag = [

    [cellphone, earphone],
    [keys, money, ID],
    [Pendrive, Coins]

];

console.log(bag[0]) // cellphone earphone
console.log(bag[1]) // keys money ID
console.log(bag[2]) // Pendrive Coins

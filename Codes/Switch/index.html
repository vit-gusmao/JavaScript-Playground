Switch

What is switch ?

Switch is a control structure that checks a value and runs the code inside the matching case, if no case matches, the default block runs instead.

Example:

let select = 2;

switch (select) {

case 1:
console.log("number 1 is selected");
break;

case 2:
console.log("number 2 is selected");
break;

default:
console.log("invalid option");
break;

}
// you chose number 2

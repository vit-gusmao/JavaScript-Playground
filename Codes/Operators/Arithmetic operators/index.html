Arithmetic operators

What are arithmetic operators ?

Arithmetic operators are used to do math with numbers: add, subtract, multiply, divide, get the remainder and increment a value.

Addition (+)

+ adds two numbers.

Example:

let a = 10;
let b = 3;

console.log(a + b); // 13

Subtraction (-)

- subtracts the second number from the first.

Example:

let a = 10;
let b = 3;

console.log(a - b); // 7

Multiplication (*)

* multiplies two numbers.

Example:

let a = 10;
let b = 3;

console.log(a * b); // 30

Division (/)

/ divides the first number by the second.

Example:

let a = 10;
let b = 3;

console.log(a / b); // 3.333...

Remainder (%)

% returns the remainder of a division.

Example:

let a = 10;
let b = 3;

console.log(a % b); // 1

Increment (+=)

+= adds a value to the variable and stores it again. a += 1 is the same as a = a + 1.

Example:

let a = 10;
a += 1;

console.log(a); // 11

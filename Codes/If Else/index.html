If Else

What is "if else" ?

"if else" is used to make decisions in the program, The if checks a condition and else runs when the if condition is false.

Example:

let age = 21;

if (age >= 18) {
console.log("You are an adult");

} else {
console.log("You are a minor");
}
// You are an adult

Else if

else if is used to add more conditions.
The order is always: if, then else if, then else.

Example:

let choice = 2;

if (choice == 1) {
console.log("choice 1");
} else if (choice == 2) {
console.log("choice is 2");
} else {
console.log("choice is 3");
}
// choice is 2

Nested if (if inside of if)

A nested if (if inside of if) checks a main condition and, only if it is true, checks another more specific condition inside it.

Example:

let age = 65;

if (age >= 18) {
console.log("You are an adult");

if (age >= 60) {
console.log("And you are also elderly");
} else {
console.log("And you are not elderly");
}
} else {
console.log("You are a minor");
}
// You are an adult
// And you are also elderly

or, and and not

These operators are used inside if to combine or invert conditions.

or (||)

|| needs only one condition to be true.

Example:

let x = 1;

if (x == 1 || x == 2) {
console.log("You typed 1 or 2");
}
// You typed 1 or 2

and (&&)

&& needs both conditions to be true.

Example:

let y = 7;

if (y >= 1 && y <= 10) {
console.log("You typed 7");
}
// You typed 7

not (!)

! inverts the condition.

Example:

let z = 5;

if (!(z != 5)) {
console.log("Correct, you typed 5");
}
// Correct, you typed 5

Includes

includes are used to check if a value is inside a list.

is inside of a list

includes checks if a value is inside an array.

Example:

let n = 2;

if ([1, 2, 3].includes(n)) {
console.log("You chose 2");
}
// You chose 2

isn't inside of a list

!includes checks if a value is not inside an array.

Example:

let n2 = 8;

if (![1, 2, 3].includes(n2)) {
console.log("The number 8 is allowed");
}
// The number 8 is allowed

Inline if else

An inline if else is declared in the variable with the ternary operator ? : or using inline if else in a variable.

Example:

let age2 = 20;
let message = age2 >= 18 ? "adult" : "minor";

console.log(message); // adult

Objects

What are objects ?

A object is a set of information with keys and values, it can be methods or properties.

Methods

Methods are values in form of function.

Properties

Properties are values in any format.

Example:

const Joao = {
completeName: "João Rodrigo da Silva",
age: 15,
showMessage: function() {
return "Welcome"; },
city: "Berlim" }

console.log(Joao.completeName); // João Rodrigo da Silva
console.log(Joao.showMessage()); // Welcome

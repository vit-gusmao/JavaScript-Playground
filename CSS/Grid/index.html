Grid

Laying out items in rows and columns

display: grid arranges children on a two-dimensional grid, defined by grid-template-columns/rows and spaced with gap.

grid-template-columns

Defines how many columns and their size, e.g. 1fr 1fr 1fr.

repeat()

Shorthand like repeat(3, 1fr) for equal columns.

gap

Sets spacing between rows and columns at once.

Example:

.cards-grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 24px;
}

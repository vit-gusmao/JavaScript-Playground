Selectors

Choosing which elements to style

A selector targets one or more elements. You can select by element name, .class, #id, or combine selectors and pseudo-classes for more precision.

Class & id

.class can repeat, #id is unique per page.

Combinators

> direct child, space descendant, + adjacent sibling.

Pseudo-classes

:hover, :first-child and :nth-child() target states or positions.

Example:

.card {
    background: #222;
}

#main-title {
    font-size: 32px;
}

nav > a {
    color: blue;
}

.card:hover {
    transform: translateY(-4px);
}

Best Practices

CSS grows fast in real projects. A few habits keep it clean, maintainable and scalable as the codebase grows.

Specificity, from lowest to highest

Element

p, div — lowest specificity.

Class

.card — beats an element selector.

ID

#header — beats classes; avoid using IDs for styling.

Habits worth keeping

Avoid !important

It breaks the cascade and is hard to override later.

Name by role

.card, not .blackBox42 — describe what it is, not what it looks like.

Mobile-first

Write base styles for small screens, add complexity with min-width queries.

Try it: also respect prefers-reduced-motion — wrap non-essential animations in @media (prefers-reduced-motion: reduce) so they turn off for users who asked for less motion, just like this site does.

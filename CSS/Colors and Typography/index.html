Colors and Typography

Giving text its look

Colors can be written as hex, rgb() or hsl(). Typography is controlled with font-family, font-size and line-height.

Color formats

#4FA8FF, rgb(79,168,255), hsl(210,100%,65%) are equivalent ways to express color.

font-family

A fallback list of fonts, e.g. 'Inter', sans-serif.

line-height

Controls vertical spacing between lines of text.

Example:

body {
    color: #FFFFFF;
    background: rgb(24, 24, 24);
    font-family: 'Inter', sans-serif;
    font-size: 16px;
    line-height: 1.6;
}

h1 {
    color: hsl(210, 100%, 65%);
}

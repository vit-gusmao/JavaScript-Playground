Box Model

Every element is a box

From the inside out, every element is made of content, padding, border and margin. box-sizing controls how width/height are calculated.

Padding & border

Space inside the border, then the border itself.

Margin

Space outside the border, between this box and its neighbors.

box-sizing

border-box includes padding/border in the declared width.

Example:

.box {
    box-sizing: border-box;
    width: 200px;
    padding: 16px;
    border: 2px solid #4FA8FF;
    margin: 24px;
}

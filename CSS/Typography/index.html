Typography

Typography is controlled with font-family, font-size, font-weight, line-height and letter-spacing.

font-family

A fallback list of fonts, e.g. 'Inter', sans-serif.

line-height

Controls vertical spacing between lines of text.

text-align & text-decoration

Horizontal alignment and underline/strikethrough.

Try it: load custom fonts with Google Fonts — this site uses Inter for both headings and UI text, loaded via a single <link>.

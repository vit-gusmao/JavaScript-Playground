Layout

CSS offers several layout systems: display and position for individual elements, and flexbox/grid for arranging groups of children.

Display

block

Takes the full width available, starts on a new line.

inline / inline-block

Flows with text; inline-block also accepts width/height.

none

Removes the element entirely, no space reserved.

Position

position controls how an element is placed relative to normal flow.

static

Default. Normal document flow.

relative

Offset from where it would normally sit, space still reserved.

absolute / fixed / sticky

Removed from flow, positioned relative to an ancestor, the viewport, or a scroll threshold.

Float

float pulls an element to one side, letting text wrap around it. Mostly legacy today — flexbox and grid replaced it for layout.

Flexbox

display: flex turns children into flex items along a single axis, controlled by justify-content, align-items and flex-direction.

Grid

display: grid arranges children on a two-dimensional grid, defined by grid-template-columns/rows and spaced with gap.

Try it: reach for flexbox when arranging items along one line, and grid when you need rows and columns together — this whole site's card grids use display: grid.

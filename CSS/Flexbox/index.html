Flexbox

Aligning items along one axis

display: flex turns children into flex items along a single axis, controlled by justify-content, align-items and flex-direction.

flex-direction

row (default) or column.

justify-content

Aligns items along the main axis: center, space-between, etc.

align-items

Aligns items along the cross axis: flex-start, center, etc.

Example:

.header-inner {
    display: flex;
    flex-direction: row;
    justify-content: space-between;
    align-items: center;
    gap: 16px;
}
